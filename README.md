YulianKb
========


A modified version of [atpmak](https://github.com/Apsu/aptmak) for left-handers coming from dvorak who prefer lower-effort/lower-travel.  This is intended for a column-staggered keyboard with dedicated thumb keys.

```
' y u l q  j f c g ?
o i a n k  b h t s r
; , . m z  x d w p v
      e
```
